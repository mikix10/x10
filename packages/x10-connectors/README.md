# x10-connectors

Connecteurs de données pour X10.

## Objectif

Fournir une base commune pour accéder aux sources externes, télécharger des données, valider leur contenu et les normaliser vers des structures X10.

## Philosophie

Les connecteurs doivent être :
- standards,
- testables,
- isolés du stockage final,
- préparés pour les sources open data et les APIs publiques.
